# Rodrigo_Jose

Este ficheiro README explica como está organizado este repositório GitHub.

## Organização

O repositório está dividido em duas pastas, correspondentes às duas disciplinas:

* **RM** - ficheiros e trabalhos da disciplina de Robótica.
* **AC** - ficheiros e trabalhos da disciplina de Aprendizagem Computacional.

## Gitignore

O ficheiro `.gitignore` define quais os ficheiros que não devem ser enviados para o GitHub.

Neste repositório, são ignorados principalmente:

* Ficheiros `.pdf` e `.zip`
* Ficheiros temporários do Python
* A pasta `__pycache__`
* Checkpoints do Jupyter Notebook
* Ambientes virtuais Python
* Ficheiros temporários do MATLAB

## Formatos de ficheiro

Os principais formatos de ficheiro utilizados neste repositório são:

* `.py` - ficheiros Python
* `.ipynb` - Jupyter Notebooks
* `.m` - ficheiros MATLAB da disciplina de RM
* `.gitignore` - ficheiro de configuração do Git

Assim, os ficheiros de código e notebooks são mantidos no repositório, enquanto ficheiros como PDFs, ZIPs e ficheiros temporários são ignorados pelo `.gitignore`.
